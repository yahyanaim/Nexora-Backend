# Nexora Backend

- The specification is `docs/CAHIER_DES_CHARGES.md`. Every change to a Must requirement is recorded in its Annex E with the reason.
- The API contract is `docs/API_CONTRACT.md` in `yahyanaim/Nexora-Saas`. Error codes are the front end's catalogue keys (Annex F).
- There is **one** audit file: `docs/AUDIT.md`. A new audit, code review or report replaces its content; do not add new dated audit or report files.
- There is **one** screenshots folder: `docs/screenshots/` (flat, JPEG quality 80). A new step or audit replaces the images in it.
